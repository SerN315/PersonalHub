# Changelog

All notable changes to PersonalHub will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-28

### 🎉 Initial Release

#### Added

- **Core Features**

  - Complete authentication system with Supabase
  - User registration and login
  - Protected routes with middleware
  - Session management

- **Widget System**

  - Drag & drop widget positioning
  - Responsive grid layout
  - Persistent widget state
  - Easy widget creation API

- **Widgets**

  - Todo List with drag & drop reordering
  - Weather widget with real-time data
  - Pomodoro timer with notifications
  - Sticky notes with color coding
  - Analog clock widget
  - Custom widget extensibility

- **Todo List Features**

  - Create, edit, delete tasks
  - Type badges (work, personal, urgent, diary, sweets, gluten, shopping, fitness)
  - Improved badge contrast for accessibility
  - Drag & drop task reordering
  - Progress tracking
  - Due date support
  - Backend persistence

- **Weather Widget Features**

  - Real-time weather data from WeatherAPI
  - Location-based forecasts
  - Animated weather backgrounds (47 GIF conditions)
  - Local PNG weather icons (47 condition codes)
  - Hourly forecast carousel
  - Auto-refresh functionality

- **Theming System**

  - 6 pre-built themes (Purple Rain, Ocean Blue, Forest Green, Sunset Orange, Rose Pink, Midnight Dark)
  - Light and dark mode support
  - Custom color accent system
  - Real-time theme switching
  - SCSS-based styling

- **Settings Panel**

  - Account management
  - Theme customization
  - User preferences
  - Settings persistence

- **Typography**

  - Bold Pixels pixel font integration
  - Multiple font size variants
  - Web font optimization ready
  - Font usage documentation

- **Technical Features**
  - Next.js 15 with App Router
  - TypeScript with strict typing
  - SCSS styling system
  - Zustand state management
  - Supabase integration
  - ESLint configuration
  - Responsive design
  - Mobile-friendly

#### Documentation

- Comprehensive README with setup instructions
- Detailed deployment guide
- Environment configuration examples
- API integration documentation
- Widget creation tutorial
- Troubleshooting guide

#### Developer Experience

- TypeScript strict mode
- Component-based architecture
- Modular file structure
- Reusable utility functions
- Clean code organization
